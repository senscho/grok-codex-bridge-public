Grok–Codex Bridge / Mac operator

Your Mac does the work.
You keep the controls.

Install the public bridge, connect one bot and keep approvals local. Commands below run on your Mac in Terminal.

1. Install and initialize

Install Homebrew if needed, then:

brew install uv tmux
brew install --cask codex
git clone https://github.com/senscho/grok-codex-bridge-public.git
cd grok-codex-bridge-public
bash scripts/bootstrap.sh
uv run --locked grok-codex register-account personal

Run the exact CODEX_HOME=... codex login command printed by registration. This isolates credentials and history for the registered account.

2. Keep private configuration local

Bootstrap creates a private .env. Edit BRIDGE_REPO_ROOTS to allow your coding directory. Keep BRIDGE_STATE_DIR outside that tree. The human token stays on this Mac; send only the Grok token to the bot's secret store. Never paste the complete configuration into a bot chat.

uv run --locked grok-codex daemon

The daemon listens on 127.0.0.1:48765. Run one worker for each state directory. Leave this terminal open or configure a local service.

3. Route the tunnel correctly

The MCP connector defaults to /codex. The bridge itself serves /tools/..., so use a path-stripping proxy. For example, install Caddy (brew install caddy) and save this as a local Caddyfile:

http://127.0.0.1:48766 {
    handle_path /codex/* {
        reverse_proxy 127.0.0.1:48765
    }
    respond 404
}

Run caddy run --config /path/to/Caddyfile --adapter caddyfile. Point an HTTPS tunnel at http://127.0.0.1:48766. The connector uses the public HTTPS origin and BRIDGE_PATH_PREFIX=/codex.

A named Cloudflare tunnel gives a stable domain. A temporary tunnel is useful for tests but its URL can change. A private network or SSH forwarding behind an HTTPS gateway is another option. If tunneling directly to port 48765, configure BRIDGE_PATH_PREFIX="" instead. Never expose the app-server or an unauthenticated public listener.

4. Install the bot connector and select the receiver

Follow BOT_INSTALL.md on the bot host. Configure its MCP launcher with the tunnel origin, external path prefix, the Mac project root as CODEX_ALLOWED_ROOT and the Grok token secret.

Pick the bot that owns Codex work. Create a webhook routine on that bot. Paste that routine's URL and exact receiver Authorization header into the Mac's private configuration:

BRIDGE_WEBHOOK_URL='https://receiver.example/routine'
BRIDGE_WEBHOOK_AUTH_HEADER='Authorization: RECEIVER_VALUE'
BRIDGE_WEBHOOK_MAX_EVENT_AGE_SEC=900

These are placeholders. Keep the generated signing secret. Restart the daemon. Only this routine's bot wakes; other bots learn through its relay. Alert for approval pending, expired login or disconnected processes, and send short finished/failed-turn wrap-ups. Install the webhook alert plus the ten-minute watchdog backup from the bot skills. Older notifications expire after 15 minutes; inspect current status after an outage.

5. Observe, approve and return control

uv run --locked grok-codex list
uv run --locked grok-codex attach SESSION_ID

Review the displayed request, then use /approve REQUEST_ID accept, decline or cancel. Use /takeover for human ownership, /steer TEXT for active work and /grok to return control. Ctrl-b d detaches tmux; /quit exits the bridge terminal. Neither stops the daemon.

For native viewing, run CODEX_HOME=/path/to/account codex resume THREAD_ID with the registered account's home. Verified Codex protection opens an app-server-held thread read-only (“opened elsewhere”). See the README for tmux history, sizing and capture commands. A built-in web viewer and detach webhook are planned.

When something needs attention

A 401 usually means the wrong token; a 403 can mean a human-only operation. Check allowed canonical repo paths if a start fails. Return ownership with /grok after a takeover. An interrupted turn is never automatically replayed: inspect changes before sending another instruction. A recovery_blocked session requires local inspection of the recorded process. Full-history API support depends on the installed Codex version; bridge attach uses retained local events.
